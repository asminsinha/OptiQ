Methodology & Limitations

Pre-Execution Feature Pipeline: Models strictly utilize pre-scheduling attributes (requested cores, requested walltime, requested memory, submit hour, submit day-of-week, and inter-arrival time). All post-outcome variables (actual runtime, actual wait time, CPU usage, and completion status) are excluded to ensure zero target leakage.

Non-Deployable Oracle Baselines: SJF (Oracle) and SRTF (Oracle) utilize actual future ground-truth burst times unavailable to practical operating system schedulers. They serve solely as theoretical lower-bound reference baselines.

Simulation Scope: Evaluated on a single logical CPU discrete-event queue model. Multiprocessor core co-scheduling and OS context-switch hardware overheads are simplified to isolate algorithmic dispatch dynamics.
